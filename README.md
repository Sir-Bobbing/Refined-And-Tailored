# Installation 
To start. you will need either MultiMC or Prismlauncher to Install the modpack.
- Both launchers follow the same install process. starting with add Instance and installing from zip via the import tab.
- You can download the required zip in the releases section of the front page of this Github.
- Once the zip has been installed, click on the instance and select the Edit button. by either selecting it on the right-hand side of the launcher,
  or by right clicking the instance and selecting it from there.
- in the edit menu, navigate down to the Settings tab, second from the bottom of the list on the left-hand side/
- once in the settings menu, select the second tab labeled "java" and click the "detect" button.
- that should bring up a window of known java installations, if Java 25 is there, select that one and test the settings just incase with the "Test settings button"
- if you don't have Java 25, you will have to find some way to install it yourself.
- Once booted, make sure you review the keybinds incase you need to change anything!


# Notes and Known Issues
## Notes
- If you disable the pre-launch command it will clear. If needed, the pre-launch command is:

  `"$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://sir-bobbing.github.io/Breaking-New-Ground/pack.toml`
- You will need to set your launcher instance to use Java 25.
- Your computer needs a minimum of 16GB of RAM to safely run the pack. The pack itself has 6GB of RAM dedicated to it in order to run. (this number could be wrong!)
